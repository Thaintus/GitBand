当项目产生新的需求、功能调整或版本迭代时，请根据迭代内容所属的业务模块：

- 若对应模块已有迭代文档，则在原文档中补充本次迭代内容；
- 若对应模块尚无迭代文档，则新建对应的迭代文档；
- 新建或更新后的迭代文档统一存放在此目录下。

迭代文档应尽量记录本次变更的背景、需求说明、实现方案、涉及文件、数据库变更、接口变更及注意事项，便于后续 AI 在新的会话中快速理解该模块的历史迭代情况。
